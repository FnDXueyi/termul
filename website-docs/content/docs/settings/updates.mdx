title: Updates

<Callout type="info">This works in the desktop app only.</Callout>

The desktop app checks for new versions of Termul and tells you when one is ready. You choose how new the versions are with a release channel.

The browser version has no update settings. It updates together with the server, so reload the page after the server updates. To update the server, see [Browser and phone](/docs/remote).

## Open the update settings

1. Open app settings with `Ctrl+,` (`Cmd+,` on macOS).
2. Select **Updates**.

The tab shows the version you have under **Current Version**.

## Pick a release channel

Under **Release Channel**, select one of these:

- **Stable** gets production releases. It is the default and the most reliable channel.
- **Insider** gets release candidates, the versions that come before a stable release. They can be unfinished.
- **Nightly** gets builds made automatically from the newest code. They can be unstable.

On **Insider** and **Nightly**, Termul does not install updates for you. It tells you about a new version and opens the release page, where you download and install it yourself.

If you installed Termul from the AUR on Arch Linux, there is no channel choice. Update with `yay -S termul-manager`.

## Check for updates

Select **Check for Updates**. If a new version is out, the tab shows **Version** and the number, followed by **is available!**. **Last checked** shows when Termul last looked.

On macOS you can also use **Help** > **Check for Updates...** in the menu bar, or press `Cmd+Shift+U`.

## Turn automatic checks on or off

**Automatically check for updates** is on by default. Termul then checks when it starts and again about every 12 hours. Turn it off to check only when you select **Check for Updates**.

## Install an update

When Termul finds a new version, a message appears in the corner of the window: **Update available: version** and the number. On Insider and Nightly, the message starts with the channel name.

1. Select **Download**. On Insider and Nightly the button is **Open Download Page**, and you install the new version yourself.
2. Wait for the download. A message shows its progress.
3. When **Update ready to install** appears, select **Install & Restart**.
4. Termul asks you to confirm. Select **Install & Restart** again, or **Not now** to install later.

Termul closes, installs the update, and opens again. Terminals that are running when you install are closed.

To hide the update message for a day, select **Remind Me**.

## See what's new

After an update, the first time Termul opens it shows a **What's New** window with the release notes of the new version.

- Select **View on GitHub** to read the release page.
- Select **Got it** to close the window.

The window shows once for each new version.
